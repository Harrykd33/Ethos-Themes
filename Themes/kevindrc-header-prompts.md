# Kevin D RC header artwork

Final assets: `header-polaroid-twilight.png`, `header-sunflare-dusk.png`, and
`header-soft-sunset-flame.png`, each 784 x 50 pixels.

The built-in image generation tool produced initial banner variants using the
prompts below. Final production headers were normalized with ImageMagick to
exact palette backgrounds and four-color bottom stripes. The original supplied
transparent Kevin D RC logo was trimmed, resized proportionally to 44 pixels
high and centered directly, preserving the original brand artwork.

Source: user-supplied `kevindrc logo.png`.
