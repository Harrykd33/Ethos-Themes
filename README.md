# Ethos Themes
Themes For Ethos system

## FrSky simulator

In VS Code, open Run and Debug and select **FrSky Simulator: Start / Restart**,
then press F5. The Ethos extension opens the simulator inside VS Code.
The workspace defaults to X18RS / FCC on the nightly26 release. Use
**FrSky Simulator: Select Radio** to change the radio or release, or
**FrSky Simulator: Open Controls** to show the transmitter controls.

The launch configuration is saved in `.vscode/`. Simulator models, radio
settings, and files persist in `simulators/<board>_<protocol>@<release>/`
across simulator restarts and VS Code sessions. This local state is ignored
by Git. Each radio and release has its own state directory.

The launcher copies `Themes/*.lua` and `Themes/*.png` into the selected
simulator's `scripts/Themes/` folder before running its command. Compiled
`.luac` files are regenerated by Ethos. After editing a theme or changing
radios, run **FrSky Simulator: Start / Restart** (F5) to load the themes.
Select a theme under **System > General > Theme**.

## XL Stratos 700

A light silver, white and red theme with the supplied helicopter image centered
in its 784 x 50 header. The photo background is transparent, and the theme uses
no black palette colors. A light green battery fill has dark green contrasting details, with a deep red
outline against a light silver header that matches the page background. The header
uses the newer helicopter image with the original STRATOS 700 lettering behind it.
See [the theme preview](previews/stratos-700-xlpower.png).
Rebuild the header with `.vscode/scripts/build_stratos_header.ps1`.

**XL Stratos 700 Dark** adds charcoal grey header and page backgrounds, bright
text and coral controls, and a pale battery outline around a blue battery fill.
See [the dark preview](previews/xl-stratos-700-dark.png).
Rebuild with `.vscode/scripts/build_stratos_header.ps1 -Dark`.

## XL Stratos 200

**XL Stratos 200** and **XL Stratos 200 Dark** take hot pink, neon yellow and
silver from the supplied canopy photo. Both feature the helicopter in a header
that matches the page background, with pink/yellow trim, a light green battery
in the light variant and a blue battery in the dark variant, with contrasting
outlines. Headers are opaque RGB for consistent radio colors.

See the [light preview](previews/xl-stratos-200.png) and
[dark preview](previews/xl-stratos-200-dark.png).
Rebuild using `.vscode/scripts/build_stratos_200_headers.ps1`, adding `-Dark`
for the dark version.

- **Polaroid Twilight**: deep violet, orchid, cream, honey and muted coral.
- **Sunflare Dusk**: ultramarine, orange, gold, pale yellow and blue.

## RC Pilot palette themes

Eight themes share an RC Pilot illustration adapted from the supplied artwork,
with centered artwork and a palette stripe in each 784 x 50 toolbar header.
Header backgrounds use each theme's background and panel colors, with no text:

- **RC Pilot Rangoli**
- **RC Pilot Electric**
- **RC Pilot Steel**
- **RC Pilot Rustic**
- **RC Pilot Rainbow**
- **RC Pilot Arctic**
- **RC Pilot Heritage**
- **RC Pilot Steel Day**

The reference contains seven palettes; Steel Day is a light version of Steel
Interface. Heritage is also light; the other six use dark backgrounds.
See [the theme preview](previews/rc-pilot-themes.png).

To rebuild these themes, run `python .vscode/scripts/build_rc_pilot.py`, then
run `.vscode/scripts/build_rc_pilot_headers.ps1` in PowerShell. The palette
manifest and header source artwork are kept in `previews/`.

## AMain themes

All four declare `studio-branding: AMain` for Theme Studio's **Branding > AMain** filter.

Four themes combine AMain orange and charcoal with the supplied Fall Mowdown
reference's cobalt blue, white, and silver:

- **AMain Carbon Dark**: charcoal panels and orange controls.
- **AMain Cobalt Dark**: deep navy and cobalt panels with orange controls.
- **AMain Orange Light**: silver backgrounds and orange controls.
- **AMain Blue Light**: cool white, pale blue panels, and cobalt controls.

Each 784 x 50 header centers the AMain logo without a background panel. Light
themes use the transparent logo; dark themes add a white outline around the
logo's gear and lettering. Orange/white/blue racing trim runs below it.
The source logo variants retain transparency; finished headers are opaque RGB
for consistent Ethos rendering. Dashboard and toolbar outlines use a shade of
AMain orange, exactly `#F87418`, as requested. Battery fills use medium blue with light text in the
dark themes and pale blue with dark text in the light themes. Warning and
critical fills are unchanged.

See the [four-theme preview](previews/amain-themes.png).
Rebuild with `python .vscode/scripts/build_amain_themes.py`; the original logo
and palette manifest are in `previews/`. The matching logo asset was obtained
from [AMain Hobbies](https://www.amainhobbies.com/content/skins/amainhobbies/images/site-logo.png).

## Battery contrast

Normal battery fills use pale green or pale blue with dark dashboard text and
blue with light dashboard text. Existing themes' text, warning fills, and
critical fills are unchanged.
Two toolbar battery outlines were adjusted to remain visible against their
existing header backgrounds.

Teal RFs, Pu RFs, Ocean, Blu Rfs, and Yelo Rfs retain their original colors
at the user's request, including their original battery fills and outlines.

Run `python .vscode/scripts/check_battery_contrast.py` to check all 47 themes
after Ethos RGB565 quantization. The 38 contrast-adjusted themes meet 4.5:1 for
normal dashboard text and 3:1 for normal fills and outlines. The four AMain themes
meet the battery text target, while preserving the explicitly requested
`#F87418` outline; some outline contrasts are below 3:1. The five restored
palettes are measured for reference without enforcing these targets.
The check samples the toolbar battery's
header artwork region and checks the dashboard header background separately.
See the [battery comparison](previews/battery-contrast.png) and
[contrast measurements](previews/battery-contrast.csv).

AMain theme palette warning and critical fills also meet 4.5:1 text contrast.
Outline measurements are reported for all three battery states. Existing themes' warning and critical measurements are included
for reference: these colors are preserved, including existing contrast issues.
The Kevd dashboard also uses its own fixed amber warning fill.
